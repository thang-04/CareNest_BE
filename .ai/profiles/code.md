# Profile CODE — Backend

Bắt đầu với L1: file liên quan, caller/callee gần nhất, test và thay đổi gần đây. Với bug, tìm index sự cố nếu đã có; incident cũ chỉ là manh mối, không phải kết luận. Chỉ mở bối cảnh nghiệp vụ khi hành vi sửa có thể đổi business rule, dữ liệu dẫn xuất hoặc hợp đồng API. Nâng lên L2/L3 theo `../ESCALATION.md` khi có dependency thực tế.

Code viết hoặc sửa phải theo `../../docs/backend-coding-guide.md` (mục router chỉ tới) và qua Checklist mục 17 trước khi báo xong.
